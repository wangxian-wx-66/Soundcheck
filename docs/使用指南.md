# 试麦员 Soundcheck · 使用指南

> 开麦前，先试麦——知乎答主发布前的信息增量体检
> 网址：`https://xxx.sealos.run`（部署后更新）

---

## 一句话理解

写回答前用**选题雷达**看这个问题的机会；写完草稿后用**开麦评审**体检你的增量。完整创作流：**雷达选题 → 写草稿 → 贴回来评审 → 确认增量够了再发布**。

---

## 快速开始（三步）

1. 打开首页，选一个入口：
   - **选题雷达**：输入问题标题（或从热榜、机会榜点一个）
   - **开麦评审**：填问题标题 + 粘贴草稿全文
2. 点击按钮，进入**研究台**——实时看 AI 检索过程（约 1-2 分钟）
3. 完成后自动跳转**战报卡**——你的体检报告

---

## 两个入口怎么选

| | 选题雷达（写作前） | 开麦评审（发布前） |
|---|---|---|
| **输入** | 只有问题，什么都不用写 | 问题 + 草稿全文 |
| **回答什么** | 这个问题还缺好回答吗 | 我的草稿有真增量吗 |
| **评级含义** | 机会评级：S 很缺好回答 → C 已被写透 | 增量评级：S 显著独有增量 → C 基本被覆盖 |
| **典型动作** | 挑一个 S/A 级问题再动笔 | 改稿（照杠精找茬清单）再发布 |

---

## 逻辑顺序（页面上从上往下看）

**研究台**（过程，约 1 分钟）：左边是 Agent 的执行步骤（解析 → 检索 → 拉标杆 → 生成报告），右边是检索进度和证据流。看不懂可以跳过，不影响结果。

**战报卡**（结果）按这个顺序读：

```
① 覆盖分析    → 这个问题别人写了什么（论点版图：灰=写透了，蓝=还缺，虚线=没人写透）
② 增量定位    → 你写的里面，哪些是真增量（蓝色=发布价值），哪些是重复劳动（灰色）
③ 争议预演    → 评论区大概率先杠你什么（主审从真实评论提炼的环境预判）
④ 评审团分歧  → 主审 vs 杠精两个 AI 各自独立评审你的草稿：
                上半是他们对评级的争吵，下半「杠精找茬 3 条」是你的改稿清单
```

---

## 读懂战报卡的关键元素

- **S/A/B/C 评级**：评级章下方有一行小字解释四档含义
- **论点版图地块**：点击任一地块，下方展开完整论点 + 判断依据 + 原文链接
- **证据角标**：每个判断标了依据来源——`社区排序`（L1）、`站内检索`（L2）、`真实评论`（L3）；「真实评论佐证」= 评论区原话，「推导」= 无直接证据的逻辑推断
- **杠精找茬**：红色左边框的条目是针对你草稿的攻击预演，每条标了「真实评论佐证」或「推导」
- **诚实边界**：所有判断基于检索摘要（非全文），报告底部可展开完整边界说明

## 常用操作

| 操作 | 说明 |
|---|---|
| **分享** | 战报卡底部「复制链接」（`/?report=xxx` 链接永久可回访）或「生成分享海报」（3:4 PNG，前端生成不上传） |
| **回看历史** | 首页「分析历史」区块，点击直接恢复战报（本地保存，登录知乎后标识云同步） |
| **中断后继续** | 分析中点「← 返回」不丢任务——首页会出现蓝色胶囊，完成后点「查看战报」 |
| **失败重试** | 研究台失败态出现「重试本次分析」按钮 |
| **登录知乎** | 顶栏「知乎登录」解锁「我的创作」（你的知乎公开创作列表，可一键选题雷达） |

## 两个常见困惑

**「我只是输入了问题，怎么会有『独有』？」**
雷达模式下蓝色地块标的是「缺好回答」——是这个问题的**机会方向**，不是说你写了什么。只有开麦评审（贴草稿）才会评「你的独有」。

**「好几处说杠点的地方有什么区别？」**
- ③ 争议预演 = **这个问题的评论区氛围**（社区会怎么杠这类回答）
- ④ 杠精找茬 = **针对你草稿的逐句攻击**（你的改稿清单）
- ④ 上半的分歧 = 两个 AI 评审员的内部争吵（有分歧的评审团比一个说了算可信）

## 隐私说明

草稿仅存本次浏览器会话（关标签页即清），服务器不存储草稿；分析时匿名发送 AI 检索比对。战报可分享，但不包含草稿全文。
