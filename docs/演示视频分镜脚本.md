# 试麦员 Soundcheck · 演示视频分镜脚本

> 目标时长：**2 分 40 秒左右，硬上限 3 分钟**（黑客松视频通行红线：绝大多数赛事要求 ≤3 分钟，超时是最常见失格原因）
> 依据：官方提交要求（视频为选交加分项，评委先看视频再看仓库）+ Devpost/黑客松策略指南最佳实践（问题→方案→冲击三幕结构，最强演示时刻放开头）
> 评分对齐：AI 场景价值 40% / 创新度 25% / 完成度 25% / 体验设计 10%——每个镜头都标注了对应得分项

## 一、录制前准备清单（10 分钟，全部勾完再开机）

### 环境

- [ ] **OBS Studio** 录制（obsproject.com，免费）：场景加「显示器捕获」+「音频输入捕获（麦克风）」，输出 1080p / 30fps / MP4
- [ ] 浏览器 **缩放调到 125%**（评委在小屏幕看，字必须大）
- [ ] **无痕窗口**打开 `https://czhuqikmrvth.sealoshzh.site`（无书签栏、无插件、无自动填充）
- [ ] **关闭所有通知**（微信/QQ/系统弹窗——一条弹窗毁一条镜头）
- [ ] 分辨率 1920×1080，只留一个标签页
- [ ] 麦克风测试：录 10 秒回放，确认无爆音、无键盘声

### Demo 状态（决定录制是否顺利的三件事）

- [ ] **提前跑一次两个模式的完整分析**（预热缓存，让正式录制时检索秒回）：
  - 选题雷达输入：`内存显卡什么时候回归正常价格啊？`
  - 开麦评审：同问题 + 准备好的草稿（见下方草稿文本）
- [ ] **录制前调 `/api/stats` 确认 `running: 0`**（别让后台任务胶囊抢戏）
- [ ] 若分析中途失败，刷新页面重试——**录制素材允许剪辑拼接**，不必一条过

## 三、录制技巧（来自实战经验）

1. **等待即旁白**：Agent 分析要跑 15-60 秒，这段是最容易冷场的——把技术解说词（第 2 幕 0:38-0:55 那段）安排在等待期念，等待反而成了「Agent 在真实工作」的证明
2. **允许剪辑**：OBS 一条录完最好，但等待段太长就剪掉，节奏 > 真实时长；**千万别倍速播放**（评委看得出来）
3. **鼠标就是教鞭**：说到哪里指到哪里，移动放慢 50%；OBS 可开启鼠标高亮效果（设置 → 高级 → 光标）
4. **念稿但不背稿**：把说辞打印或放第二屏照着念，语气自然比背诵流利更重要；每句之间允许自然停顿
5. **录两遍取优**：第一遍找节奏，第二遍正式录；素材分开存
6. **隐私红线**：全程不要露出任何环境变量、后台终端、密钥管理页面——只录浏览器
