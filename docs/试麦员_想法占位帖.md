# 试麦员 · 参赛想法占位帖（含防抄袭发布节奏）

> 用途：发布知乎想法 → 同步「黑客松脑洞补给站」圈子 → 复制链接填入报名表单「参赛想法链接」字段
> 人气奖计分：9.13-9.23 想法点赞量 + 使用量 + 评论量

---

## 一、主推版本（直接复制）

```
写完一个回答，光标停在发布键上的那几秒，你有没有犹豫过——
这个问题下，是不是早就有人把我想说的说完了？

我们是「试麦员 Soundcheck」队，参加知乎黑客松·校园新锐季，赛道：知识炼金场。

正在做的工具，一句话：开麦前，先试麦。
它会在你按下发布键之前，替你做最后一次检查。

具体检查什么、怎么检查，48 小时后揭晓。
只透露两条情报：
① 评审员不止一位，而且他们经常吵架；
② 检查完会打一个分数，但我们还没商量好这个分数叫什么名字。

队伍目前 [N] 人（[你的背景一句话]），还缺一位 [前端/设计] 队友，评论区捞人。

点赞催更：过 100 解锁第一张概念图，过 300 提前拉内测群。
```

（约 330 字；[] 内按实际情况填写或整段删除；需要时可加 1-2 个表情，不加也成立）

## 三、防抄袭逻辑（这版帖子藏了什么、露了什么）

**露的（安全）**：
- 痛点共鸣（发布前的犹豫）——这是创作者普遍焦虑，不算我们的机制
- 队名 + slogan（品牌资产，露了反而是占位声明）
- 「评审员不止一位且吵架」——多 Agent 方向官方手册本来就公开列了（「Agent 与 Agent 之间的新型社区互动模式」），露了无损失
- 「打一个分数」——只暗示游戏化评级，不透露 S/A/B/C 战报系统

**藏的（核心，9/14 中午前绝不出现）**：
- 增量对比机制（对比同问题已有高赞回答）
- 争议预演（预测评论区反驳）
- 选题雷达（输入问题出论点地图）
- 战报卡/研究台的视觉设计

## 五、发布操作清单

1. 发布想法时勾选同步到「黑客松脑洞补给站」圈子
2. 主帖配图：logo 或悬念概念图（不放产品截图）
3. 发布后复制想法链接，贴回报名表单
4. 发布后 1 小时内回复所有评论（互动信号有算法加权）
5. 拉票：亲友自然转发点赞可以；**刷点赞是官方明文作弊判定项（同一设备/多账号刷人气 = 取消资格），绝对不做**
6. 后续每篇新想法（开工帖/成品帖）的点赞评论同样计入人气奖，按上表节奏持续发

## 六、备选替换句

- 开头备选（更扎心）：「你花三小时写的回答，可能只是别人三年前某个回答的复述。」
- 情报①备选：「评审团内部有分歧时，我们会把分歧原样给你看。」
- 若已有队伍不想招人：删除招募段，替换为「团队 N 人，产品/技术/设计齐活，就差把 48 小时过成 96 小时。」
