## 一、完成内容

### 1. 分享海报（开麦战报卡 → 传播核心）

**技术决策（v2.18 定稿，偏离原计划）**：原计划 html2canvas 转 3:4 竖版 PNG。实现前核查发现两个阻断性理由，改用**原生 Canvas 2D 手绘**：

1. 本项目 CSP 为 `style-src 'self'`（无 unsafe-inline）——html2canvas 依赖把 computed style 以内联样式写入克隆 DOM，存在被 CSP 阻断风险；
2. 需引入 ~200KB vendor 依赖，违背项目「零运行时依赖」现状与 80/15/5 视觉预算纪律。

手绘方案零依赖、无 CSP 冲突，且与既有「手写 SVG 数值条」的视觉纪律一致。**依据：CSP 规范 + 工程判断（推断级，浏览器实测兜底验证）。**

**实现**（`public/poster.js`，纯前端，不碰后端）：
- 900×1200 逻辑尺寸，2x 出图（1800×2400），高分屏传播不糊
- 版面：品牌行（Path2D 复用顶栏麦克风 SVG 路径）→ 评级章（S/A/B/C 大字 serif + 分级配色）→ 问题标题（CJK 逐字换行，3 行截断）→ 结论行 → 四维体检条 → 论点版图 4×3 地块（灰=覆盖 / 蓝=独有描边 / 虚线=空白）→ 独有增量 top3 → 争议预演第一条 → 底部钉住的溯源声明 + 蓝色回访链接（`/?report=run_id`）
- 弹窗预览（遮罩/ESC/×三路关闭）+ `toBlob → a[download]` 下载 PNG

**浏览器实测（browser agent）**：海报 canvas 1800×2400 渲染成功，评级方框/标题/进度条/地块/链接各元素像素级确认存在；下载按钮可点、无 console 报错。

### 2. 热榜机会榜（今日热榜上还缺好回答的 3 个问题）

**实现**（`lib/opportunity.mjs` + `server.mjs` 路由 + 首页 `#opp` 区块）：
- **评分（纯函数 `scoreOpportunity`，不烧 LLM token）**：空缺度 gap = 100 − 证据量；证据量 = 最高赞(≤40, 1000 赞封顶) + L4 权威条数(≤30) + 深度内容条数(≤30) + 问题被索引收录(+10)。口径透明，前端理由行直接展示（「相关内容 N 条 · 最高 M 赞 · L4 权威 K 条」）
- **数据链**：hot_list(20) 取前 8 候选 × 每候选 1 次 zhihu_search(10)——单次预计算 ≤8 次搜索（5000/天额度，<0.2%），完全在「少量搜索」预算内
- **缓存与预计算**：结果落 search_cache（api_type `opportunities`，TTL 13h）+ 后台每 12h 预计算（每日 ≤2 次，缓存不空档）+ 请求侧兜底现算（≈6s）；预计算失败静默，下次重试
- **失败隔离**：单候选搜索失败跳过；全部失败显式 `OPPORTUNITY_EMPTY`（不静默空榜）
- 前端：#1-#3 排名 + 空缺度进度条 + 理由行，点击填入选题雷达

**真数据实测（意外即真实测）**：本地联调时一次环境变量传递失误导致真 key 服务短暂启动，后台预计算跑了真实数据——出榜 gap 57/53/50（LPL 总决赛评价 / 罗永浩冰激凌舆情 / 河北医大二院受贿），浏览器实测确认前端渲染正常。消耗：1 次 hot_list + 8 次 search（日额度占比可忽略）。此误操作已如实记录。
