## 二、交付物

### 1. Dockerfile（单容器全栈）

- **白名单 COPY**：package.json / server.mjs / lib/ / public/ / scripts/ / docs/ / hackathon.config.json——密钥与数据由 .dockerignore 双重拦截，**永不入镜像**
- **密钥只经 Sealos Secret 运行时注入**（代码零硬编码，process.env.*）
- `node:22-alpine`（node:sqlite 依赖 Node ≥22）+ **npm 源写死 npmmirror**（白名单国内镜像，Sealos 构建环境不继承本机 config）
- **非 root 运行**（USER node）+ `/data` 持久卷（chown node）+ DATA_DIR=/data
- HEALTHCHECK 30s（/api/health 不消耗额度）
- 容器内端口固定 `PORT=4173 HOST=0.0.0.0`（修复：HOST 默认读 config 为 127.0.0.1，容器内必须 0.0.0.0）
- 依赖层缓存顺序（package.json 先拷）；本项目零运行时依赖，`package-lock.json*` 通配容错

### 2. .dockerignore（防泄漏第一道闸）

`.env` / `.env.*` / `*.key` / `secrets/` / `data/` / `*.db*` / `node_modules/` / `.git/` / `.trae/` / `.vscode/`——即使 Dockerfile 误写 `COPY . .` 也会被此文件拦截

### 3. pre-commit 密钥扫描钩子（补安全纪律缺口）

- **零依赖方案**：项目无 devDependencies，不引 husky/detect-secrets 供应链面——Node 原生实现 `scripts/pre-commit-scan.mjs`
- 安装：`git config core.hooksPath .githooks`（.githooks/pre-commit → node scripts/pre-commit-scan.mjs）——**hooks 目录入版本库，克隆即生效**（优于 .git/hooks 不随仓库走）
- 规则：私钥块 / sk- key / ghp_ token / AKIA / JWT / 凭证赋值语句；只扫暂存区**新增行**，跳过注释与空模板行
- 自测通过：真实 DeepSeek key 格式 ✅ 命中、知乎 secret 格式 ✅ 命中、URL/空值/普通代码 ✅ 不误伤
- 误报逃生口：`git commit --no-verify`（人工确认后）
